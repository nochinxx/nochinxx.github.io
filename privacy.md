# Privacy Policy

**Last updated:** July 30, 2026

## Overview

This privacy policy applies to the personal automation tools and internal applications operated by Mario Jimenez ("the developer") using Google APIs, including Gmail.

## Application Purpose

This application is a **personal internal automation tool**. It is not a commercial product or public service. It is used solely by the developer to manage and process email for internal purposes.

## Data Collection and Use

This application accesses Gmail data (reading, sending, and organizing email) exclusively for the personal use of the developer. No data is:

- Shared with third parties
- Stored on external servers
- Used for advertising or analytics
- Accessible to anyone other than the developer

## Google API Services

This application uses the Gmail API. Use of Google API data is limited to what is necessary for the application to function and is handled in accordance with [Google's API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy).

## Data Storage

Any email data processed by this application is stored locally on the developer's personal machine and is not transmitted to any external service.
